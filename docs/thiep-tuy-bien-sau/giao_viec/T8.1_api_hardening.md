# T8.1 — Sửa client API theo review T8 (vòng 1)

- **Sub-agent**: `frontend-ui` · **Đợt**: 4 · **Phụ thuộc**: T8 · **Review**: có
- **Tệp được sửa**: `js/api.js`, `index.html`

## Phải sửa
1. `request()`: AbortController timeout 30s (upload/publish 60s); hết giờ → Error "Máy chủ phản hồi quá chậm, vui lòng thử lại." và nút được mở lại.
2. Race QR: trong `.then` của nạp qrcodejs, xoá `qrEl` rồi chỉ vẽ nếu slug/url vẫn là cái đang hiển thị.
3. SRI cho qrcodejs 1.0.0 (cdnjs): `integrity="sha512-CNgIRecGo7nphbeZ04Sc13ka07paqdeTu0WR1IM4kNcpmBAUSHSQX0FslNhTDadL4O5SAGapGt4FodqL8My0mA=="`, `crossOrigin="anonymous"`, `referrerPolicy="no-referrer"` (hash do phiên chính tính từ tệp cdnjs).
4. `copyFrom`: chỉ báo "Đã sao chép!" khi thật sự thành công; thất bại → chọn sẵn nội dung ô và báo "Hãy bôi đen và sao chép thủ công".
5. `closePublishModal` xoá `.value` của ô edit key.
6. `openPublishModal` gọi lại `checkHealth()` nếu `!available` (backend bật sau khi mở trang); tooltip nút ghi "Chạy backend rồi tải lại trang hoặc bấm lại".
