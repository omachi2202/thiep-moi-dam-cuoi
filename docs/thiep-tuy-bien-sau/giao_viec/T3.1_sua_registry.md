# T3.1 — Sửa registry theo review T3 (vòng 1)

- **Sub-agent**: `frontend-ui` · **Đợt**: 3 · **Phụ thuộc**: T3 · **Review**: có
- **Tệp được sửa**: `js/state.js`, `js/render.js`, `js/sections/album.js`, `js/sections/events.js`

## Phải sửa
1. **N1 — id trong handler inline**: `migrate` chuẩn hoá `sec.id` khớp `^[a-z0-9_-]{1,40}$`, là chuỗi, duy nhất; sai/trùng/thiếu thì sinh `<type>-<n>` (giữ nguyên các id cũ hợp lệ như `hero`). Sửa `selectedSectionId` nếu trỏ tới id đã đổi. `selectSection` và mọi selector dùng `CSS.escape` (có fallback khi không có `CSS`).
2. **N2 — CSS injection**: whitelist trong `sectionVars` (và mọi chỗ khác chèn state vào `style=`): màu `^#[0-9a-f]{3,8}$`i (sai → mặc định), font phải thuộc `FONT_OPTIONS` (value) hoặc là font mặc định của `DEFAULT_STATE.globalStyle`, cỡ chữ `Number` kẹp 12–72. Viết helper `safeColor`, `safeFont`, `safeSize` trong `state.js` (gắn `window`) để các section sau dùng lại.
3. **N3 — focusout**: lưu giá trị gốc lúc `focusin`; chỉ gọi `updateSectionField` khi đổi; đọc bằng `textContent` có chuẩn hoá `<br>`/khối thành `\n` (không dùng `innerText` vì `text-transform`); bỏ qua khi `appState.isPreviewMode`.
4. **N4 — chịu lỗi**: `renderCardHtml` bọc `renderCanvas` từng section bằng try/catch (editor: khối cảnh báo nhỏ; invite/export: bỏ qua section) và tự `migrate` bản sao khi `state.schemaVersion !== SCHEMA_VERSION`; album dùng `Array.isArray(d.photos) ? d.photos : []`.
5. Gợi ý cần làm luôn: `migrate` không hạ `schemaVersion` khi state mới hơn (giữ nguyên, `console.warn`); `sec.style` không phải object thường → thay bằng `{}`; `fieldAttr` escape `key`; nút chỉ đường events chỉ nhận `http(s)` — URL rỗng/không hợp lệ thì ẩn nút.

## Tiêu chí đạt
Kiểm bằng vm: id `x');alert(1);//` bị đổi thành `<type>-<n>`; `customTextColor = "red;position:fixed"` → không xuất hiện `position:fixed` trong HTML; state thiếu `photos` đưa thẳng vào `renderCardHtml` không ném lỗi; migrate vẫn idempotent; canvas mặc định không đổi.
